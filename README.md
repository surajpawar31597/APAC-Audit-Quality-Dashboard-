# APAC-Audit-Quality-Dashboard-
Morningstar APAC Audit Quality Dashboard 📊
# Short Description / Purpose
An executive-level Power BI analytics solution designed to monitor, track, and optimize data quality, defect percentages, and audit performance across multiple APAC markets for document acquisition operations. The dashboard provides leadership and analysts with granular visibility into error trends, root causes, and individual contributor performance.
# Tech Stack
Data Visualization & BI: Power BI (Desktop / Service)
Data Modeling & Calculation: DAX (Data Analysis Expressions), Power Query
Data Prep & Querying: SQL, Relational Databases
Documentation & Version Control: Git & GitHub
# Data Source
Internal Morningstar operational audit logs, document acquisition (DA) transaction records, and quality assurance error-tracking tables covering APAC markets.
# Features & Highlights
# 1.Business Problem:-
Managing high-volume document acquisition across diverse APAC markets (including Japan, Thailand, Singapore, Malaysia, Australia, and New Zealand) introduces risks of categorization, mapping, and metadata errors. Without centralized tracking, identifying systemic data quality bottlenecks and evaluating workflow accuracy across regions and team members becomes inefficient.

# 2.Goal of the Dashboard:-
   Establish a single source of truth for APAC audit quality metrics.
   Track overall compliance against strict data accuracy benchmarks (maintaining >99% quality).
   Isolate defect hot spots by geography, timeline, and error category to drive targeted process improvements.
   Provide transparent performance tracking for Document Analysts (DAs).
   
# 3.Walkthrough of Key Visuals:-
**Header KPI Cards:** Instant snapshot of core metrics including Total Audits (2.656K), Total Defects (25), Defect % (0.94%), Quality % (99.06%), Markets Covered (7), and Total Active DAs (5).

**Monthly Audit Trend:** Dual-axis line and marker chart tracking total audit volumes alongside defect counts and flat high-quality trends over time.

**Defect Heatmap (Market vs. Month):** Matrix view mapping out exact defect distributions across countries (Thailand, Australia, Singapore, Japan, Indonesia, Malaysia, New Zealand) across monthly cycles.

**Top Defect Categories (Root Cause Analysis):** Horizontal bar breakdown isolating specific error types—leading with Subdoctype Error (8), Effective Date Error (7), and Mapping Issue (5), down to document classification and language errors.

**Defects by Market:** Comparative regional bar chart highlighting total error volumes per country.

**DA Performance Table:** Detailed tabular breakdown evaluating individual Document Analysts (Suraj, Monika, Ruta, Vedanth, and Ravindra) across total audits handled, defects logged, and individual quality percentages.

# Business Impact:-
Error Reduction: Enabled precise root-cause targeting for high-frequency errors like subdoctype and effective date mismatches.
Operational Excellence: Maintained a sustained 99.06% quality rate across thousands of processed audits.
Enhanced Accountability: Provided clear performance metrics across regional markets and individual analysts to streamline workflow reviews and continuous quality enhancement.
